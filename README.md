# Neural Networks for Handwritten Digit Recognition using the MNIST Dataset

We will work with neural networks for image classification. The aim is to obtain models capable of making reliable predictions on images from the well-known MNIST dataset of 28×28 pixel images of handwritten digits in grayscale. For this purpose, we will use some images of digits as training and validation sets, and we are looking for models that perform well on test data that the model has never seen before.

We will use TensorFlow to train the neural networks. The selected models will be a MultiLayer Perceptron (MLP), a Gated Recurrent Unit network (GRU) and a Convolutional Neural Network (CNN).

MultiLayer Perceptrons are basic feedforward neural networks. The proposed MLP receives as input a flattened vector of 784 values. There are two hidden layers with 512 and 256 neurons, respectively, whose weights are initialized using the He Normal initializer to suit the ReLU activation function. Each hidden layer is followed by Batch Normalization, which stabilizes and accelerates training by normalizing the Dense layer outputs, then a ReLU activation layer that introduces non-linearity and a Dropout layer with a rate of 0.1 to reduce overfitting. The output layer contains 10 neurons, one for each digit class, uses the Softmax activation function to produce class probabilities, and employs Glorot Uniform weight initialization, which is well suited for the output layer. The model is trained using the Adam optimizer with a learning rate of 0.0001, minimizing the sparse categorical cross-entropy loss function while monitoring classification accuracy as the evaluation metric.

Gated Recurrent Unit models are a type of Recurrent Neural Network and they are designed to process sequential data. The proposed GRU network receives as input each handwritten digit as a sequence of 28 time steps, where each time step corresponds to one row of the 28×28 grayscale image and contains 28 pixel values. The recurrent feature extraction stage consists of two stacked GRU layers with 128 and 64 units, respectively. The first GRU layer is configured with return_sequences=True so that it outputs the complete sequence to the second GRU layer, enabling the network to learn hierarchical sequential representations. Both recurrent layers use Glorot Uniform initialization for the input kernel and Orthogonal initialization for the recurrent kernel, a combination that is well suited to the internal tanh and sigmoid activation functions of GRU cells and helps preserve stable hidden-state dynamics during training. They also incorporate both dropout and recurrent dropout with a rate of 0.2 to regularize the input and recurrent connections, thereby reducing overfitting. The features extracted by the recurrent layers are then passed to a Dense layer with 64 neurons using the ReLU activation function and He Normal initialization, providing a nonlinear classifier before the final prediction stage. An additional Dropout layer with a rate of 0.2 further improves generalization. Finally, the output layer consists of 10 neurons with a Softmax activation function and Glorot Uniform initialization, producing the probability distribution over the ten digit classes. The model is trained using the Adam optimizer with a learning rate of 0.0001, minimizing the sparse categorical cross-entropy loss function while monitoring classification accuracy as the evaluation metric.

Convolutional Neural Networks are deep learning models designed to process and analyze structured grid data, such as images and video. The proposed CNN receives as input a 28×28×1 grayscale image represented as a single-channel tensor. The feature extraction stage consists of two convolutional blocks. The first block contains two 2D convolutional layers with 32 filters of size 3×3, using He Normal weight initialization and no bias terms. Each convolution is immediately followed by Batch Normalization, which normalizes the feature maps, and then a ReLU activation function to introduce non-linearity. The block concludes with a 2×2 Max Pooling layer to reduce the spatial dimensions of the feature maps and a Dropout layer with a rate of 0.25 to mitigate overfitting. The second block follows the same structure but increases the number of filters to 64, enabling the network to learn more complex and abstract visual features. After the convolutional stage, the resulting feature maps are flattened into a one-dimensional vector and passed to a fully connected layer with 128 neurons, employing ReLU activation and He Normal initialization. A Dropout layer with a rate of 0.5 further regularizes the classifier before the final output layer, which consists of 10 neurons with a Softmax activation function and Glorot Uniform initialization to produce the probability distribution over the ten digit classes. The model is trained using the Adam optimizer with a learning rate of 0.0001, minimizing the sparse categorical cross-entropy loss function while monitoring classification accuracy as the evaluation metric.
